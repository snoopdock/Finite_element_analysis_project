\section{Introduction and Scope of the Finite Element Method}

The method's robustness to mesh size and polynomial order, as demonstrated by the mesh size and polynomial order trade-off, ensures reliable performance across diverse applications \cite{ref1}. This is particularly evident in the use of higher polynomial orders, which reduce discretization error more rapidly than mesh refinement. In contrast, primal finite element methods solve PDEs without additional fields, relying on direct discretization of primary variables, and are termed 'irreducible' \cite{ref6}. However, these methods face challenges in problems with constraints or incompressibility, where mixed formulations excel. The mixed finite element method, on the other hand, introduces additional fields to solve PDEs, constrained using Lagrange multipliers, enabling efficient solutions for numerically ill-posed problems \cite{ref6}.

The theoretical foundations of the Finite Element Method (FEM) are rooted in the weak formulation and Céa's Lemma.

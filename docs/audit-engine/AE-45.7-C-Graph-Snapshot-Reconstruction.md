**Depends on:** validated B graph report and C0/C1 preflight/request package

## 1. Purpose

C2 independently reconstructs the graph snapshot that a future C investigator would use. It copies only the exact files admitted by the embedded A baseline manifest, verifies the copied-scope digest, builds AE-32B with the same NetworkX backend, and compares the resulting graph identity to the B report.

The verifier checks source revision, graph source-manifest digest, graph fingerprint, graph projection version, evidence-index status, active backend, graph node/edge counts and native query-path wiring. It also reuses C0's B-integrity checks, including per-query provenance consistency.

## 2. Security boundary

C2 does not import `providers.factory`, `RepositoryInvestigator`, or provider SDKs. It does not read credentials, construct a provider, call a model or dispatch a workflow. The output schema hard-codes:
- `provider_dispatch_permitted=false`;
- `provider_calls_attempted=0`;
- `credentials_accessed=false`.

A graph fingerprint mismatch, incomplete B snapshot, task/source mismatch or source mutation blocks verification.

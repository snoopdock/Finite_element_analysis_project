# G3.2.0 — Graph Evolution and Audit Memory Foundation

## Purpose

G3.2.0 extends the validated G3.1 audit chain across repository states. It answers a different question from verification: not only *what was established?*, but *does that conclusion still apply after the semantic graph changes?*

## Architecture

```text
SemanticGraph(t)
      |
      v
GraphSnapshot(t)
      |
      +------------------+
                         |
SemanticGraph(t+1)       |
      |                  |
      v                  |
GraphSnapshot(t+1)       |
      |                  |
      +------> GraphDelta
                  |
                  +--> TopologyDelta
                  |
                  +--> InvalidationReport
                  |
                  +--> AuditLongTermMemory
```

## Important boundary

Topology remains descriptive. Degree, component count, isolation, or relation frequency do not establish importance, severity, correctness, or scientific truth.

## Invalidation semantics

`current` means the audited state is unchanged.

`recheck_required` means the graph changed but no direct contradiction or evidence removal was established.

`stale` means a semantic-context assumption changed or directly referenced evidence disappeared.

## Memory

Long-term memory is append-only historical evidence. It is not a mechanism for silently restoring findings as current knowledge.

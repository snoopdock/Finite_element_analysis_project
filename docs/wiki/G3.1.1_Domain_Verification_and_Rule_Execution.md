# G3.1.1 — Domain Verification and Rule Execution

G3.1.1 moves the semantic audit system from verification infrastructure to
meaningful policy execution while preserving the architecture established in
G3.0 and G3.1.0.

Three initial deterministic domains are supported: architecture dependency
constraints, required semantic relationships, and evidence provenance
completeness. Each domain converts an explicit graph-analysis target into a
verification obligation and receipt before a declarative rule may create a
finding.

The milestone deliberately treats absence and topology as graph-scoped facts.
For example, a missing `SUPPORTED_BY` edge means the relationship is absent
from the audited graph snapshot; it does not prove the scientific claim has no
support anywhere else.

This prepares later G3.2 work on snapshots, semantic deltas, invalidation and
long-term audit memory without coupling those concerns into domain policy.

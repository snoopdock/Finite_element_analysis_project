# G3.3.1 Adaptive Verification Escalation and Budget-Aware Replanning

G3.3.1 adds outcome-driven continuation to the G3.3 orchestration layer.

The runtime now supports:

```text
Initial plan
   ↓
Bounded execution
   ↓
Explicit outcome
   ↓
Adaptive replan
   ↓
Unattempted eligible verifier
   ↓
Continuation execution
```

The initial plan budget remains the session-wide hard ceiling. Replanning cannot reset resource accounting, repeat an attempted verifier by default, create findings, mutate canonical semantic knowledge, or persist to long-term memory.

Adaptive escalation is operational. It does not mean that a more expensive verifier is more truthful, nor that an inconclusive result is evidence of a defect. The continuation planner merely chooses another explicitly profiled capability after the previous route failed to satisfy the verification objective.

G3.3.1 also converts G3 validation workflows 05–12 to manual `workflow_dispatch` execution only.

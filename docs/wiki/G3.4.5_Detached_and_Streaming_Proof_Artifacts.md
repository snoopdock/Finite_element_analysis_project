# G3.4.5 — Detached and Streaming Proof Artifacts

G3.4.5 allows large RUP/DRAT proof certificates to live outside the external solver JSON response without allowing the solver to choose arbitrary files or URLs.

A detached certificate contains only a trusted store ID, SHA-256, exact byte size, proof format, CNF digest, and fixed artifact-format metadata. Trusted application code owns the mapping from store ID to storage. The first implementation is a local content-addressed store.

The repository verifies artifact integrity and then checks `semantic_cnf_proof_jsonl/v1` line by line. Proof steps are not accumulated in memory, although the active clause database remains resident because RUP/RAT semantics require it. A valid detached proof can promote a large external UNSAT observation to `VALIDATED / CERTIFICATE_COMPLETE_WITHIN_SCOPE`.

Missing storage, digest mismatch, malformed input, or resource exhaustion are operational validation failures, not semantic counterclaims. External solver execution remains inactive by default, and workflows 05–19 remain manual-only.

# G3.3.0 — Audit Orchestration and Cost-Aware Verification

## Motivation

A mature autonomous auditor may have multiple ways to test the same obligation. Some are inexpensive structural checks; others may eventually require static analysis, solver work, executable witnesses, sandboxed tests, or controlled external tools.

Running every verifier for every candidate is neither scalable nor scientifically necessary. G3.3.0 therefore introduces a reproducible orchestration layer.

## Architecture

```text
Obligation
   |
Objective: required evidence state
   |
Compatible verifier set
   |
Resource / containment profiles
   |
Explicit budget and policy
   |
Orchestration plan
   |
Bounded execution with planned fallbacks
   |
Verification receipts
```

## What cost means

`cost_units` are relative planning units under a versioned policy. They are not milliseconds, dollars, confidence, probability, semantic importance, or truth.

This distinction is essential. A cheap verifier is not weaker merely because it is cheap; an expensive verifier is not more correct merely because it costs more.

## Evidence capability

A profile declares a maximum evidence-state capability such as `CORROBORATED` or `VALIDATED`. This is a ceiling that allows planning; an individual execution may still return `INCONCLUSIVE`.

## Fallbacks

The planner may reserve a bounded sequence:

```text
cheap deterministic check
       |
       | inconclusive
       v
stronger planned verifier
```

The executor cannot invent new fallback actions from evidence or verifier output.

## Security

G3.3.0 adopts an important autonomous-auditor rule: source artifacts, documentation, graph metadata and tool output are evidence, not instructions. Only a precomputed plan authorizes verifier execution.

## Future work

Later G3.3 batches may add measured cost calibration, adaptive replanning, solver/executable verification, and budget-aware integration with G3.2 re-verification plans. Learned prioritization remains advisory and deferred until deterministic orchestration is mature.

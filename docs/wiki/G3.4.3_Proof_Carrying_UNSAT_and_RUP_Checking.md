# G3.4.3 — Proof-Carrying UNSAT and Repository-Owned RUP Checking

## Purpose

G3.4.3 extends the controlled external CNF pathway with the first scalable negative certificate. An external solver may now return an UNSAT proof, but the proof is authoritative only after a repository-owned checker validates it.

## Architecture

```text
controlled external solver
        ↓
UNSAT + proof certificate
        ↓
exact CNF digest binding
        ↓
proof-format registry
        ↓
repository-owned proof checker
        ↓
step-by-step inference validation
        ↓
empty-clause derivation
        ↓
VALIDATED + certificate_complete_within_scope
```

The external solver still cannot self-promote evidence.

## Initial proof format

The first proof format is `cnf-rup/v1`.

For every proof clause `C`, the checker validates the RUP condition:

```text
current_formula ∧ NOT(C)
        ↓
Boolean unit propagation
        ↓
contradiction required
```

Only then is the clause added to the working formula. The final proof clause must be empty.

This gives a sound UNSAT certificate without replaying the producing solver's search.

## Deliberate limitations

The initial checker is not DRAT or LRAT. It supports clause addition only. It does not accept deletion steps, RAT inference, LRAT hints, SMT theory lemmas, or proof literals outside the declared variable range.

Those omissions are explicit so unsupported proof languages cannot be silently approximated.

## Resource limits

Proof certificates are untrusted external data. The RUP checker therefore applies hard limits to proof step count, total proof literals, and clause width.

Hitting a limit means only that the repository could not validate that proof under the configured envelope. It does not imply SAT.

## Fallback semantics

If an external RUP proof is invalid but the CNF is small enough for the independent bounded checker, the repository may still establish SAT or UNSAT by exhaustive enumeration. The invalid proof itself remains rejected.

For a larger CNF with an invalid or unsupported proof:

```text
external UNSAT
      +
invalid/unsupported proof
      ↓
OBSERVED + PARTIAL
```

## Why this matters

G3.4.3 is the first point where the repository can validate a larger external UNSAT result using a proof rather than an exhaustive truth table. This creates the architectural path for future DRAT/LRAT or theory-proof support without weakening the existing evidence boundary.

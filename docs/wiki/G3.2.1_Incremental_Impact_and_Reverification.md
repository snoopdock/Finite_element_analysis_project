# G3.2.1 — Incremental Impact Propagation and Re-verification Planning

## Purpose

G3.2.1 makes semantic auditing incremental across graph revisions.

The central question changes from:

> Did the source graph change?

into:

> Which previous audit artifacts depended on the changed semantic region, and what work must be repeated?

## Architecture

```text
GraphSnapshot(t)
      +
GraphSnapshot(t+1)
      ↓
GraphDelta
      ↓
ChangeAtoms
      ↓
ArtifactDependencyIndex
      ↓
ImpactPropagationReport
      ↓
ReverificationPlan
```

## Change Atoms

Graph deltas are normalized into backend-neutral changes such as:

- node added;
- node removed;
- node modified;
- semantic edge added;
- semantic edge removed;
- semantic context changed.

These are facts about evolution, not judgments.

## Dependency Profiles

Analysis artifacts describe their semantic footprint: source entities, discovered entities, evidence, observations, relevant relation vocabulary and impact scope.

Receipts point to source analyses. Findings point to receipts. This makes downstream propagation explicit rather than inferred from naming conventions.

## Fine-Grained Validity

For bounded local analyses, a distant unrelated graph change may remain `current`. A relevant neighborhood change becomes `recheck_required`. Removal of directly referenced evidence or the source entity makes the affected analysis `stale`.

That state propagates to dependent receipts and findings.

## Re-verification Planning

The planner produces work requirements, not executions:

```text
analysis              → rerun_analysis
verification receipt  → reverify_receipt
finding               → reevaluate_finding
```

Tasks preserve their upstream prerequisites.

A versioned operational priority score helps triage work but does not represent semantic importance, truth, confidence, or scientific validity.

## Non-goals

G3.2.1 does not add:

- automatic execution;
- topology-driven semantic judgment;
- learned impact prediction;
- GNN inference;
- automatic candidate promotion;
- cross-repository audit scheduling.

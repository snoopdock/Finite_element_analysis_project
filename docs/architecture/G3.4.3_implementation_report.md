# G3.4.3 Implementation Report — Proof-Carrying UNSAT and RUP Checking

## Scope

G3.4.3 adds a repository-owned UNSAT proof-checking subsystem to the controlled external CNF verifier. It does not activate the placeholder `formal/` subsystem and does not add arbitrary external proof-checker execution.

## Runtime additions

### `high_assurance/unsat_proof.py`

Provides:

- `UnsatProofCheckerDescriptor`;
- `UnsatProofCheckerRegistry`;
- `UnsatProofCheckResult`;
- `ProofCheckLimits`;
- `RupUnsatProofChecker`;
- deterministic RUP/unit-propagation validation;
- built-in registry construction for `cnf-rup/v1`.

### `certificate_validation.py`

The external UNSAT certificate path now distinguishes:

1. repository-owned proof checking;
2. bounded independent exhaustive validation;
3. unsupported/invalid proof observation.

A valid proof reaches `VALIDATED` with `certificate_complete_within_scope`. An invalid proof can never self-validate. Small formulas may still be independently resolved by the pre-existing bounded checker.

### `external_solver.py`

The controlled external CNF adapter now owns an explicit proof-checker registry and records the registered proof formats in its validation envelope. No proof checker is sourced from the external solver process.

## Soundness boundary

The RUP rule implemented is:

`F ⊢ C` when Boolean unit propagation on `F ∧ ¬C` derives conflict.

Each accepted proof clause extends `F`; the final accepted clause must be empty. This establishes UNSAT for the exact CNF bound by `cnf_digest`.

## Security boundary

Proof certificates are parser/checker inputs, not executable instructions. The proof checker imports no subprocess API and does not use the placeholder formal routing layer.

Resource exhaustion is operationally neutral: proof-limit failure never means SAT.

## Deferred work

G3.4.3 intentionally defers:

- DRAT and LRAT proof checking;
- external proof checker binaries;
- SMT theory proofs;
- theorem-prover proof terms;
- OS-sandboxed solver execution;
- any inference from proof size to confidence or scientific importance.

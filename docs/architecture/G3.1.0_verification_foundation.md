
# G3.1.0 Verification Foundation

## Status
Implementation candidate.

## Objective
G3.1.0 introduces the verification boundary between graph observations and semantic audit findings.

## Runtime chain

```text
GraphQuery
 -> GraphAnalysisResult
 -> VerificationObligation
 -> Verifier
 -> VerificationAttempt
 -> VerificationReceipt
 -> SemanticAuditRule
 -> RuleEvaluationResult
 -> AuditFinding
```

## Important distinctions

### Observation is not verification
G3.0 structural analysis may establish that an edge or path exists in the canonical graph. G3.1 does not reinterpret that as program feasibility, scientific truth, or policy compliance.

### Evidence state is not verification decision
Evidence maturity (`observed`, `corroborated`, `validated`, etc.) is tracked separately from verifier outcome (`confirmed`, `refuted`, `inconclusive`, `error`).

### Verification is not policy
Verifiers answer bounded obligations. Declarative rules decide whether a verified result matches policy.

### Policy match is not finding creation
Finding creation is a guarded final step and requires a triggered `RuleEvaluationResult` bound to the same immutable receipt.

## Initial verifiers

### ObservationContractVerifier
Deterministically confirms/refutes an explicitly requested subject/predicate/object observation pattern. It does not infer a policy from that pattern.

### EvidenceCorroborationVerifier
Establishes corroboration only when evidence provenance exposes explicit independent source groups. Multiple edges alone are not treated as independent evidence.

## Candidate knowledge
`CandidateKnowledge` provides a neutral container for future learned or heuristic proposals. It intentionally has no canonical graph mutation API.

## Semantic context
Every analysis result now exposes a versioned semantic context. Analysis identity and verification are sensitive to context changes even when the canonical graph fingerprint is unchanged.

## Compatibility
The existing `VerificationStatus` import path from G3.0 remains available and is expanded with G3.1 lifecycle states. Existing graph analyzers remain pure observation producers. The repository's older domain-specific `analysis/semantic_verifier.py` remains a scientific-content component and is not replaced by this generic graph verification substrate.

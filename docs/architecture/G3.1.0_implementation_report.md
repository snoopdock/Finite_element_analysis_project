
# G3.1.0 Implementation Report

## Scope
This patch implements the generic verification substrate above G3.0 semantic graph analysis. It does not add production domain policy rules, solver integration, executable reproduction, long-term audit memory, or neural graph inference.

## Added packages

- `audit_engine.semantic_audit.verification`
- `audit_engine.semantic_audit.rules`
- `audit_engine.semantic_audit.findings`

## Added capabilities

- versioned semantic interpretation context;
- deterministic verification obligations;
- verifier descriptors and registry;
- explicit verifier selection;
- immutable verification receipts;
- deterministic observation-contract verification;
- provenance-aware corroboration verification;
- safe declarative YAML rule loading;
- receipt-bound rule evaluation;
- guarded deterministic finding creation;
- finding lifecycle/staleness support;
- isolated candidate knowledge model;
- machine-readable contracts and JSON schemas;
- G3.1 CI validation artifact.

## Preserved boundaries

- graph analysis imports no verification/rule/finding code;
- verification imports no rule/finding code;
- candidate knowledge cannot mutate the canonical graph;
- graph backends remain absent from G3.1 semantic layers;
- existing domain-specific scientific verifiers remain separate adapters/consumers rather than semantic authorities for the generic layer.

## ADR numbering note
Earlier discussion drafts used `ADR-035` for the verification boundary. The repository already assigns ADR-035 to the graph visualization boundary in the G3 design sequence. G3.1 therefore uses ADR-036 through ADR-040. Those numbers are authoritative for this patch.

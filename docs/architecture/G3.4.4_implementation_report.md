# G3.4.4 Implementation Report — Repository-Owned DRAT Proof Checking

G3.4.4 extends the proof-carrying UNSAT boundary from addition-only RUP to a bounded structured DRAT checker. The implementation is intentionally a reference checker: small enough to audit, deterministic, repository-owned, and isolated from external execution.

## Runtime additions

`audit_engine/semantic_audit/high_assurance/drat_proof.py` adds `DratUnsatProofChecker`, `DratProofCheckLimits`, the `cnf-drat/v1` format, RUP-or-RAT clause admission, strict deletion, proof digesting, resource ceilings, and formal-proof witnesses. The built-in UNSAT proof-checker registry now exposes both RUP and DRAT formats explicitly.

RAT is checked on the first literal of the candidate clause. For every active clause containing the opposite pivot, the checker constructs the resolvent. Tautological resolvents are discharged immediately; every other resolvent must be RUP against the current active formula. Clause additions and deletions update only proof-checker state. The final accepted step must add the empty clause.

## Evidence semantics

A valid DRAT certificate reaches `VALIDATED / CERTIFICATE_COMPLETE_WITHIN_SCOPE` through the existing certificate-validation boundary. Invalid, unsupported, or resource-limited proofs do not become semantic counterclaims. For small formulas, the independent bounded exhaustive checker may still establish the verdict without trusting the external proof.

## Security and architecture

The DRAT checker has no subprocess, network, graph mutation, finding, promotion, or memory dependency. The existing controlled external solver adapter can advertise DRAT only because the repository-owned checker is registered. The external solver never controls the checker implementation or evidence-state promotion.

## Deferred work

Native textual DRAT parsing, LRAT/FRAT hints, clause-ID proof languages, high-performance watched-literal propagation, proof streaming, detached proof artifacts, and separately contained proof-checker executables remain future work.

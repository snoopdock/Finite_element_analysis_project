# G3.2.0 Graph Evolution Foundation

## Implemented capabilities

- immutable semantic graph snapshots;
- deterministic snapshot and delta identities;
- semantic-context drift reporting;
- node and edge regression diffs;
- backend-independent descriptive topology summaries;
- topology deltas;
- current/recheck/stale invalidation semantics;
- append-only durable audit-memory ledger;
- JSON serialization and round-trip loading;
- high-level graph-evolution service.

## Explicitly deferred

G3.2.0 does not implement:

- semantic importance from graph centrality;
- graph motif policy;
- automatic remediation;
- neural anomaly detection;
- fine-grained proof-preserving invalidation of absence-based verifications;
- historical merge/rebase semantics.

Those require additional contracts and evidence models.

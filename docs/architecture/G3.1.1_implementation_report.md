# G3.1.1 Implementation Report

## Status

Implementation candidate pending CI validation.

## Added capabilities

- graph-aware verification contexts with graph fingerprint binding;
- graph attribute constraint verifier;
- required relationship verifier;
- provenance completeness verifier;
- domain rule model, YAML loader and end-to-end executor;
- guarded candidate-to-canonical promotion service;
- architecture, scientific-support and provenance example rules;
- machine-readable domain-rule and promotion contracts/schemas;
- ADR-041 and ADR-042;
- G3.1.1 validation workflow and deterministic validation artifact.

## Preserved boundaries

G3.0 analysis remains observation-only. G3.1.0 receipts remain immutable.
Rules still cannot create findings without an eligible verification receipt and
triggered rule evaluation. Candidate promotion is not a verification shortcut.

# G3.2.1 Implementation Report

## Milestone

**G3.2.1 — Incremental Impact Propagation and Re-verification Planning**

## Implemented

### Fine-Grained Change Model

`GraphDelta` is normalized into deterministic change atoms covering node, edge and semantic-context changes.

### Artifact Dependency Index

The new index captures analysis footprints and explicit analysis → receipt → finding lineage. It detects unresolved upstream references rather than silently assuming lineage exists.

### Impact Propagation

Local structural/dependency analyses can remain current after proven-unrelated edits. Relevant neighborhood edits require recheck. Direct evidence loss, source-entity removal and semantic-context changes produce stale state. State propagates downstream monotonically.

### Re-verification Planner

The planner creates deterministic tasks for rerunning analyses, re-verifying receipts, and reevaluating findings. A versioned priority policy supports operational triage while remaining explicitly non-semantic.

### Audit Memory Queries

Append-only memory can now be queried by artifact, snapshot, evidence, receipt and rule identity without mutation or promotion.

### Contracts and Governance

Added ADR-046 through ADR-048, four YAML contracts, three JSON schemas, architecture tests and workflow 09 acceptance validation.

## Explicitly Deferred

- automatic execution of re-verification tasks;
- cost-aware orchestration with real runtime cost estimates;
- graph-centrality or topology-based prioritization;
- learned/GNN impact prediction;
- distributed audit memory;
- cross-commit automatic candidate promotion.

## Acceptance Standard

The milestone is acceptable only if previous G3.0–G3.2.0 suites remain green, new impact/re-verification tests pass, the architectural validator passes, and the full repository regression remains green locally.

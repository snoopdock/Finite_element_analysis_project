# G3.3.1 Implementation Report

## Scope
G3.3.1 implements adaptive verification replanning and bounded multi-round orchestration on top of G3.3.0.

## Components
- `orchestration/replanning.py`: remaining-budget accounting, adaptive policy, objective decisions, immutable continuation plans.
- `orchestration/adaptive.py`: bounded session execution and cumulative accounting.
- planner eligibility is reused through a public `eligible_profiles` function so the same policy checks govern initial and continuation planning.
- profile catalogs expose a deterministic read-only profile view.

## Invariants
1. The original budget is never reset.
2. An attempted verifier is excluded from continuation by default.
3. A continuation verifier must be registered, profiled, compatible, permitted, and budget-feasible.
4. Failed verification is not retried unless adaptive policy explicitly permits it.
5. No finding, promotion, graph mutation, or memory persistence occurs implicitly.
6. G3 GitHub validation workflows are manual-only.

# G3.5 — Integrated Semantic-Audit Exit Gate

## Purpose

Close feature expansion within G3.4 and supply **one read-only application API**:
`decision_memory.assurance_integration.create_cycle(repository, query, draft, ...)`.
It composes:

1. G3.4.18 decision-memory retrieval (through `proposal_audit.audit`).
2. G3.4.19 claim-by-claim citation tracing and source-byte verification.
3. G3.4.20 deterministic review-dossier construction.
4. G3.4.21 optional self-declared human-review annotations.
5. A structured review route and **graph-engine handoff projection**.

The projection deliberately does **not** use SAT proof to infer natural-language
entailment, and it does not implement operational graph persistence. Each edge
means only that a claim *cites a local record*, not that the record supports it.

## Stable API

- `create_cycle(root, query, draft, max_results=8, review_submission=None, github_actor='unknown')`
- `verify_cycle(cycle, root, review_submission=None, github_actor='unknown')`
- CLI `python -m decision_memory.assurance_integration --repository <checkout> --query ... --draft-file ... --output <path-outside-checkout>`
- CLI independent verification: `--repository ... --verify-file <cycle.json>`

## Structured output

`schema_version`, `source_commit_sha`, `audit`, `dossier`, optional
`review_annotations`, `graph_handoff` (typed claim/memory nodes and citation edges),
`review_routes`, `summary`, `authorization`, `cycle_sha256`.

All authorization flags are fixed `false`. Reviewer statements, successful tests,
citation hashes and graph edges cannot change those flags. Changes to cited
records cause a source-bound verification failure.

## Exit criteria for the G3.4 track

- One end-to-end test proves retrieval, audit, dossier, routing, and projection.
- Adversarial tests cover uncited claims, unresolved records, historical conflicts,
  rule candidates, forged review submissions, modified source bytes, tampered
  report fields, output safety and digest determinism.
- Existing repo regression passes through `Manual Validation Dispatcher`.
- **No claim of scientific truth, graph correctness or automatic action authority.**

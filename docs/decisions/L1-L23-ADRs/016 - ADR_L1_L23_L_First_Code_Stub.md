# ADR --- First Code Implementation Stub

## Status

Accepted

## Context

The architecture is ready for implementation, but existing repository
migration has not started.

------------------------------------------------------------------------

# Decision

Create minimal executable stubs before integration.

------------------------------------------------------------------------

# Reasoning

This provides:

-   executable contracts;
-   early testing;
-   safe migration.

------------------------------------------------------------------------

# Consequence

The first implementation is intentionally incomplete. Its purpose is
architectural validation.

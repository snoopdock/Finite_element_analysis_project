# ADR --- Change of Implementation Strategy

## Status

Accepted

## Context

The previous planning stages created many architectural documents but
repeated similar abstraction levels.

## Decision

Move from architecture expansion to concrete milestone-based
implementation.

## Reason

The architecture is sufficiently defined.

The next value comes from:

-   inspecting actual code;
-   implementing boundaries;
-   validating behavior.

## Consequence

Future steps will contain fewer conceptual documents and more
repository-specific actions.
